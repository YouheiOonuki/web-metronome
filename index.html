この道具について（使い方・計算のしくみ・注意）

メトロノームでできること

BPM 1〜500 のテンポでクリック音を鳴らします。4/4・3/4・6/8 のほか 5/8・7/8 などの変則拍子、裏拍や3連の刻み、少しずつ速くする練習にも対応し、楽器の基礎練習、合奏前のテンポ合わせ、リズム感のトレーニングに使います。

使い方の要点

  • スライダー・「＋」「－」・数値入力で BPM を決めます。曲のテンポがわからないときは、曲に合わせて「TAP」を4回ほど押します。
  • 「拍子・リズム」のプリセットから拍子を選び、「再生」を押します。1拍目（強拍）は拍インジケーターの色が変わります。
  • 縦のバーをタップするたびに、その拍が「強 → 中 → 弱 → 休符」と切り替わります。

鳴らし方のしくみ

クリック音は Web Audio API で鳴らす時刻を先に予約するので、画面の処理が重くなってもずれにくい仕組みです。BPM は1拍（拍子の分母の音符）あたりの数で、6/8 を付点4分音符 = 60 で数えたいなら BPM を180にします。「2+2+3」のようにグルーピングを入れると、まとまりごとの頭に中アクセントが付きます。練習モードのテンポアップは決めた小節数ごとにテンポを少しずつ変え、無音小節は途中で音を消して、自分でテンポを保てているかを確かめます。

注意

端末やブラウザの状態によってわずかな誤差が出る場合があります。録音や本番の演奏など、厳密なテンポが必要な場面では専用の機器も併用してください。イヤホンやヘッドホンで使うときは、音量を下げてから再生し、少しずつ上げてください。BPM・拍子・アクセント・音色などの設定は、この端末のブラウザ（localStorage、キー metronome-settings）にだけ保存され、外部には送信されません。消去は画面の「設定」のボタンから。

細分化の種類、音色、ホーム画面への追加はメトロノームの使い方ガイドに。
