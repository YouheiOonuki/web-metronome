免責事項

当アプリのクリック音は、ブラウザの Web Audio API を使って鳴らしています。テンポの正確さには配慮していますが、端末やブラウザの状態によってわずかな誤差が生じる場合があります。録音や本番の演奏など、厳密なテンポが求められる場面では、専用の機器を併用してください。当アプリの利用によって生じたいかなる損害についても、運営者は責任を負いかねます。

イヤホンやヘッドホンで使うときは、音量を下げてから再生し、少しずつ上げて調整してください。大きな音を長時間聴き続けると、耳を傷めるおそれがあります。

当アプリの内容は、予告なく変更・終了する場合があります。

当アプリに掲載する広告は、第三者配信事業者によるものです。広告の内容や、広告先のサイトで提供される商品・サービスについて、運営者は責任を負いません。

著作権

当アプリのデザイン・文章・プログラムの著作権は運営者に帰属します。ユーザーが設定したデータ（BPM・拍子・アクセントなど）は、ユーザーのブラウザ内にのみ保存され、運営者が取得することはありません。
