About This Site

このサイトについて

このサイトは、ブラウザだけで使えるシンプルな無料 Web メトロノームです。 アプリのインストール不要・ログイン不要で、スマートフォン・タブレット・PC のどのデバイスでも即座に使えます。

主な機能

  • BPM 設定 — スライダー・数値入力・増減ボタンで 40〜240 BPM を自由に設定
  • タップテンポ — TAP ボタンを連打するだけで曲のテンポを自動計測
  • 正確なクリック音 — Web Audio API のスケジューリングで音のズレを最小化
  • BPM の記憶 — 前回設定した BPM をブラウザに自動保存
  • レスポンシブデザイン — スマホでも快適に操作できる UI

開発者について

このサイトは Youhei が個人プロジェクトとして開発・運営しています。 音楽と Web 技術が好きで、練習中に「シンプルで軽いメトロノームがほしい」という思いから作りました。

フィードバックや改善要望は GitHub Issues からどうぞ。

技術スタック

  • HTML / CSS / JavaScript（フレームワーク・ライブラリなし）
  • Web Audio API（音声スケジューリング）
  • localStorage（BPM の保存）
